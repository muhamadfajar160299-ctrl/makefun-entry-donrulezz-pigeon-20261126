One line, 200 characters at most, in English: the elevator pitch a city
pigeon gives to investors for its startup.

Run `python3 main.py` and it writes the pitch to `entry.txt`
(and to `/output/entry.txt` when that directory exists), byte-exact and
deterministic: the same line on every run.
